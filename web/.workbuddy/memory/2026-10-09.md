## 命令式 Element Plus 弹层统一收敛到 @/utils/alert（修复按需加载后掉样式）

- **根因**：迁移按需加载后，脚本里显式 `import { ElMessageBox/ElMessage/ElNotification } from "element-plus"` 会绕过 `ElementPlusResolver` 的样式注入（resolver 只处理模板标签与自动导入标识符），导致弹窗/消息 CSS 缺失、变裸样式。JobResultList 的「取消」确认框（ElMessageBox.confirm）因此掉样式。
- **修复**：所有命令式弹层统一走 `src/utils/alert.js`（集中 import 组件 + 对应 `style/css`）。alert.js 补 `import "element-plus/es/components/{message,notification,message-box}/style/css"`，并新增 `$confirm(message, title, options)` 封装 `ElMessageBox.confirm`（默认 warning + 确定/取消按钮，可覆盖）。
- **调用点改造**：JobResultList.vue 的 `ElMessageBox.confirm` → `$confirm`（import 改 `@/utils/alert`）；router/index.js 与 utils/fetch.js 的裸 `ElNotification` → `$nerror`；全仓仅 alert.js 保留对 element-plus 的 import。
- **验证**：`vp build` 通过；dist `main-*.css` 已含 el-message-box / el-notification / el-message 样式。
